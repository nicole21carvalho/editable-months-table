# 📅 Tabela de Meses Editável

Tabela com os 12 meses do ano em que dá para **adicionar linhas e editar qualquer célula** direto no navegador. Feita com HTML, CSS e JavaScript puro.

## ✨ Funcionalidades

- ➕ Botão para adicionar uma nova linha à tabela
- ✏️ Dois cliques numa célula para editar o valor
- ⏎ Enter ou clicar fora salva a edição

## 🛠️ Tecnologias

HTML · CSS · JavaScript (manipulação do DOM e eventos)

## 🚀 Como executar

Baixe o repositório e abra `teste/teste.html` no navegador.
